# Harcorp: delivery notes

All videos are 1920×1080, 30 fps, H.264 with stereo AAC 320k. Audio is mastered to about −14 LUFS with a true peak of −1.5 dBTP or below, so nothing clips.

| File | What |
|---|---|
| Harcorp_Logo_DirectionA_Acquisition.mp4 | Logo A, 5s. A targeting system scans, builds and locks onto the mark. The wordmark prints, then a clean hold. |
| Harcorp_Logo_DirectionB_FromThePoint.mp4 | Logo B, 5s. One point bursts into a field of characters ("matter"). The field condenses into the lockup, locks cell by cell and turns solid, then a clean hold. |
| HARCODE_Demo_15s.mp4 | 15s launch film. The idea: say the change, and HARCODE writes it in your terminal. |
| Harcode_Component_Reel_32s.mp4 | Six components in turn, each with build-on, idle and build-off. |
| Harcode_Component_Sheet_3840x2160.png | Still of all six components, plus the palette and type. |

**Palette:** near-black #050607, phosphor #E4ECE7, one accent #5DF2C6 for active states only, and red #FF3B3B for alerts only.

**Type:** Departure Mono for labels and headlines, JetBrains Mono for code. Both are under the SIL Open Font License.
